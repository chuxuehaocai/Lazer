# Lazer v2.0.0-beta.4

本次预发布重点加入可自定义多个每日暂停时段的「定时关闭」，并整合字体、设置、播放页、背景与原生音频引擎的一系列更新。

## 定时关闭

- 在「设置 → 播放 → 定时关闭」添加多个每天重复的暂停时段，支持编辑、删除、总开关及每个时段独立启停。
- 支持跨午夜，例如 `23:00–07:00`；也可同时设置午休等其他时段。重叠时段会合并生效。
- 到达开始时间后暂停当前歌曲并保留队列和进度。时段内保持暂停，结束后由用户手动继续，不会突然恢复播放。
- 设置会保存到本机，重启后继续生效；回到前台时重新检查，并处理等待中的播放命令越过暂停边界的情况。
- 移动端使用独立设置页面，桌面端使用设置内的子视图。支持简体中文、繁体中文、英语和日语。
- 时间按设备本地时间计算。该功能暂停音乐，不退出应用或关闭设备；应用被系统完全挂起时，可能延后至恢复运行后执行检查。

## 字体与设置

- 界面统一使用 MiSans，集中提供多个文字类别的大小与粗细调节，并支持歌词字体设置、实时预览和恢复默认。
- 字体、快捷键、均衡器等编辑界面在移动端作为独立页面打开，在桌面端以带动画的子视图呈现。
- 桌面设置子视图采用桌面布局，返回时保留原列表位置，修复返回闪烁。
- 「正在播放背景」更名为「动态背景」，相关选择控件与设置界面保持一致。
- 「高保真播放」集中管理音频引擎、导入引擎、设备及均衡器设置。新增日志导出，便于反馈播放与界面问题。

## 移动端正在播放

- 新增「歌词同时显示封面」：点按封面后，封面缩小并移动到左下方，与歌曲信息对齐。
- 小封面去除阴影，与媒体控件同步收起；控件隐藏时，顶部显示小封面、标题和歌手，点按可恢复控制。
- 封面移动采用先快后慢的非线性动画，支持中途反向切换；优化竖屏、横屏、小屏及大字号布局。
- 顶部精简歌曲信息区域下移，增加与系统顶部区域的间距。该布局仅影响启用上述设置的移动端，桌面播放页保持独立布局。
- 修复拖动进度条时进度闪回，拖动预览与实际播放器时钟保持协调。
- 修复移动端从后台返回后歌词和进度条偶发停留在旧位置：暂停后恢复播放会重新启动进度更新，回到前台立即校准实际播放位置，并清理中断的拖动预览与旧歌词动画。

## 背景、主题与性能

- 浏览页面共享同一背景，正在播放页面可单独配置；支持动态、静态、纯色和自定义图片。
- 浏览背景默认限制为 30fps，播放背景默认跟随显示刷新率，并可手动调整至最低 10fps。
- 静态模式保留动态背景生成的一帧；纯色背景可自选颜色或根据主题生成。
- 切歌时立即刷新由封面生成的主题，减少旧歌曲异步结果覆盖新歌曲颜色的问题；暗色封面保持可读对比度。
- 优化歌词布局、封面内存、缓存扫描及动画资源回收；修复页面过渡动画监听器累积。
- 减少页面切换时重复布局与后台绘制，保留辅助功能并修复 Windows 无障碍树更新错误。
- 改进滚动惯性和歌单拖动排序，排序结果持续保存。不同设备和复杂场景的帧耗时仍会有差异。

## Audio Engine

- Android arm64-v8a / x86_64 接入完整原生引擎，使用 FFmpeg 解码及 AAudio 输出，包含连续播放、DSP 和文件读取桥接。
- 修复 Android 部分写入、暂停/恢复、输出协商及原生日志生命周期问题；原生库支持 16KiB 页面对齐。
- Windows、Linux、macOS 和 Android 的可运行构建产物随附引擎及所需依赖。Windows 包内包含 `lazer-audio.dll`、读取桥及 FFmpeg DLL。
- 新安装默认优先使用内置原生引擎，缺失或无法初始化时回退至系统引擎；保留用户手动选择系统引擎或导入引擎的设置。
- Windows 开发构建会复用已配置或已缓存的 FFmpeg SDK，随 Flutter 构建编译引擎并更新根目录开发 DLL；发布包使用自身随附的引擎。
- Windows 构建增加实际加载检查，验证主隔离区和音频工作隔离区都能加载包内引擎及读取桥。
- Android 使用系统共享 PCM 输出，不提供桌面独占或原生 DSD 直通保证；iOS 继续使用系统播放引擎。

## 音乐服务与其他修复

- 整合音乐服务连接和 Navidrome 支持，更新多平台内容与播放状态的衔接。
- 合并桌面布局、外部链接打开、osu! 搜索及相关界面更新。
- 修复 Android 发布签名校验及构建工具路径问题，补充签名辅助工具和构建说明。

## 下载与升级

- Windows：下载并完整解压 ZIP，保持 EXE、DLL 和 `data` 文件夹在一起。
- macOS：提供通用版和 Intel 版 App 压缩包。
- Linux：提供 x86_64 和 ARM64 AppImage。
- Android：通用 APK 包含 arm64-v8a 和 x86_64 原生引擎。
- iOS：提供未签名 IPA，需要自行签名安装。
- 每份可运行包附带 SHA-256 校验文件。Android 构建另附引擎对应源码和重新链接材料。

这是预发布版本。升级前可备份本地配置；反馈问题时可从「设置 → 关于 → 导出日志」附上诊断信息。
