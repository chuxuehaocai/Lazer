# Lazer v2.0.100

Lazer v2.0.100 是 v2.0.0 之后的稳定更新，新增网络源、桌面 / 悬浮歌词、系统托盘和完整 Web 版，并集中修复播放、账户切换、插件、存储与界面稳定性问题。

Lazer v2.0.100 is the stable update after v2.0.0. It adds network sources, desktop / floating lyrics, a system tray and the full browser build, with fixes across playback, account switching, plugins, storage and interface reliability.

## 🌐 网络源 / Network sources

- 音乐库新增「网络源」页面，支持 WebDAV、FTP、SFTP 和 SMB2 网络存储；四种协议均由 Dart 直接实现，不依赖系统挂载或原生客户端。
- 网络存储可浏览目录、扫描音频并索引进音乐库；播放通过本机回环 HTTP 网关转发，支持 Range 拖动和断点续传。
- 新增网络电台与播客订阅：电台支持 M3U / PLS / ASX / XSPF，播客支持 RSS 2.0 / Atom，按单集保存播放进度并标记已听完。
- 网络源密码保存在应用数据目录的 AES-GCM 保险库中；Android 与 iOS 补充了明文网络和本地网络权限声明。
- 修复网络源页面进入 / 离开时的外壳切换动画，并加固真实服务器暴露出的路径、认证和重定向处理。

## 🎤 歌词 / Lyrics

- Windows 新增桌面歌词：歌词绘制在桌面壁纸上，支持点击穿透、拖动位置和 1–5 行显示。
- 全平台新增悬浮歌词窗口，复用正在播放页的弹簧歌词引擎；支持字号、字重、字体、模糊强度和动画速度设置。
- 播放进度每 50 ms 同步一次；切行时保持弹簧连续性，修复抖动、跳变和切换歌曲后的残影。
- 前奏与间奏显示呼吸三点动画，保留显式空白时间段；桌面歌词默认 3 行，可配置为 1–5 行。
- 关闭歌词开关后立即关闭对应窗口，不再残留绘制；桌面歌词仅显示文字，不绘制背景卡片。

## 🌍 Web 版 / Web build

- 浏览器现在运行完整的原生界面，而不只是插件演示壳；插件登录、歌单、播放与本地音频继续可用。
- 新增同源 `/api/plugin-http` 转发函数，浏览器不能自行指定 `X-Real-IP` / `X-Forwarded-For`。
- Web 字体改为子集，首屏字体体积从约 22 MB 降到约 2.3 MB；CanvasKit 与入口文件使用内容哈希和 immutable 缓存。
- 修复移动浏览器文字自动放大、引擎资源重复下载和 Web-only 源码的静态检查问题。

## 🛠 改进与修复 / Improvements and fixes

- 修复暂停后切歌、再点播放仍播放旧歌曲的问题；现在会打开当前选中的歌曲。
- 修复安装插件后登录，首页与资料库仍显示未登录数据、必须重启进程才恢复的问题；登录后会切换到刚认证的平台并刷新首页、歌单和喜欢列表。
- 修复封面返回时的回弹、首页歌单封面 key 不稳定以及快速重开时的空帧。
- 修复音量软件调节被引擎拒绝时不显示原因、HiFi 输出设置未及时生效、播放头在恢复后跳回旧位置等问题。
- 插件市场现在校验每个包的清单、路径、体积和媒体规则；数据目录迁移增加失败次数上限，避免反复迁移卡住启动。
- 新增播放失败自动跳过：服务器拒绝或音频源不可用时按设置跳过当前歌曲，队列不会停在无法播放的条目上。
- 桌面端新增「关闭到系统托盘」：关闭窗口后继续播放，托盘菜单提供播放 / 暂停、上一首、下一首和退出。
- 补充 HiFi 路径、插件权限、歌词悬浮窗设置和 ZIP 错误提示的四语言本地化；发布 CDN 重试与本地化覆盖检查纳入 CI。
- 刷新 Flutter 3.47.0 的依赖锁文件，并补齐 Linux 桌面测试依赖，保持各平台 CI 一致。
- 修复多个失效控件、过期交互状态和设置页布局问题。

## 📦 下载与升级 / Downloads and upgrades

| 平台 / Platform | 文件 / File |
| --- | --- |
| Windows x86_64 | `Lazer-Windows-x86_64.zip` |
| macOS Universal | `Lazer-macOS-universal.zip` |
| macOS Intel | `Lazer-macOS-x86_64.zip` |
| Linux x86_64 | `Lazer-Linux-x86_64.AppImage` |
| Linux ARM64 | `Lazer-Linux-aarch64.AppImage` |
| Android | `Lazer-Android-universal.apk` |
| iOS | `Lazer-iOS-aarch64.ipa` |

- Windows：下载并完整解压 ZIP，保持 EXE、DLL、资源与 `data` 文件夹在一起。
- macOS：使用 ad-hoc 签名，首次打开请右键 → 打开，或在「系统设置 → 隐私与安全性」中放行。
- Linux：`chmod +x` 后运行 AppImage；GTK 与 libmpv 已包含在包内。
- Android：通用 APK 使用仓库发布密钥签名，可覆盖安装同一签名的 v2.0.0。
- iOS：提供未签名 IPA，需使用 AltStore、SideStore 或 TrollStore 等工具自行签名。

每个可运行包都附带 SHA-256 校验文件。升级前建议备份本地配置；反馈问题时可从「设置 → 关于 → 导出日志」附上诊断信息。
