# Lazer v2.1.0

Lazer v2.1.0 adds a finished Still Alive easter egg experience and carries the latest playback, interface, and CI fixes from the `nextgen` branch.

## Highlights

- The Still Alive credits animation now stops cleanly when the soundtrack ends.
- Playback completion pauses the easter egg soundtrack and returns to the page that opened it.
- Added regression coverage for soundtrack completion and automatic navigation.
- Updated the release mascot artwork.
