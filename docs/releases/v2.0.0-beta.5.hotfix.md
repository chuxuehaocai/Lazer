# Lazer v2.0.0-beta.5.hotfix

本次热修复统一桌面与移动端的正在播放页弹簧动画，重做歌单文字过渡，并修复播放页背景在动画落地或中断后消失的问题。同时包含封面与歌词预加载、Android 数据存储、系统媒体控制和原生音频引擎首播方面的稳定性修复。

## 动画与交互

- 设置新增「动画速率」拉杆，范围 0.5×–2.0×，默认 1.0×；调节会实际改变页面、播放页、歌单封面、弹窗和交互反馈等弹簧动画的感知时长，并在重启后保留。
- 震动反馈开关与强度继续接入按钮、卡片和滑块的统一反馈层；新增的动画速率拉杆也按该开关与强度提供按格触感。
- 桌面与移动端正在播放页使用同一套非线性 Bouncy 物理弹簧：感知响应时长为 600 毫秒，bounce 为 0.15；页面允许自然超越目标后回弹。
- 打开、关闭、拖动释放和中途反向都从当前呈现位置与速度继续，不叠加固定时长缓动、刹车段或第二套动画时钟。
- 正在播放页使用独立页面动画，播放栏封面、歌名和歌手不再通过共享元素飞入页面；歌单卡片与详情页继续保留各自的封面和文字交接。
- 修复正在播放页背景在动画落地或中断后消失的问题；背景在整个弹簧过程中持续绘制，仅在上方越界时补底，避免露出下层页面。
- 修复点击歌单卡片进入详情、返回时歌单名和数量被截断、末尾字符临时缺失或落地前闪现的问题。过渡保留两端排版，只更新绘制图层的位置、缩放和交接。
- 歌单封面和文字使用保留的绘制图层，动画期间不反复重建、换行或重新排版；移除重复的飞行计时器。
- 修复首页歌单卡片进入详情、返回及快速重开时封面层交接的空帧和闪烁，保留首页滚动位置；离场页面的重复封面和文字保持隐藏。
- 修复字体设置、定时关闭等二级页面与上一页控件重叠显示的问题，覆盖手机路由和桌面内嵌页面。
- 启用系统「减少动态效果」时直接完成页面和元素交接，保留键盘、遥控器和辅助功能操作。

## 播放页与缓存

- 切歌时即开始预加载清晰封面，并在内存中保留当前歌曲的已解码图片。再次打开正在播放页可直接复用；切换封面时释放旧缓存，同专辑封面共享解码结果。
- 同时预加载歌词，保留最近八首歌曲的解析结果，包括逐字时间与翻译。打开播放页复用已有请求；手动刷新和导入歌词修改会更新缓存，旧请求不会覆盖新歌曲。
- 歌词首帧直接对齐当前播放进度，避免进入页面时先挤在一起、等动画结束后才恢复。
- 封面或歌词在进入动画中加载完成时及时刷新画面，避免占位图一直停留到动画结束。

## Android 数据存储与系统媒体

- 设置中新增「数据存储」，可申请「所有文件访问权限」并指定 `/sdcard/Lazer` 等绝对路径；更改目录后重启生效。
- 已有缓存、歌词、导入字体和本地音乐索引会迁移到新目录，原文件保留；支持恢复默认目录，并在所选目录不可访问时暂用应用默认目录。
- 适配 Android 17（API 37）的后台音频限制：从可见 Activity 启动媒体播放前台服务后再发布播放状态。
- 修复 Android 控制中心的上一首、下一首命令在应用切到后台后无法继续驱动现有播放队列的问题。

## 原生音频引擎

- 修复下一首预解码占用工作线程、阻挡当前歌曲首次播放的问题，避免需要反复切换播放/暂停才能启动。
- 修复读取器错过下载完成通知的问题；对无法估算长度的网络流使用引擎自身的缓冲路径，避免把「未知」当成空缓冲一直等待。
- 保留兼容引擎的无缝队列预取行为和主音量同步。

## 其他修复

- 修复 Still Alive 彩蛋播完后点击「重新播放」没有音乐、停在 Test Report，以及重播时残留播放状态的问题。
- 修复下载提示过期时操作入口消失的问题，并保留现有队列、歌词和设置行为。
- 清理仅用于输出诊断信息的测试，保留播放、手势、文字排版、过渡交接与资源释放的回归检查。

## 下载与升级

- Windows：下载并完整解压 ZIP，保持 EXE、DLL 和 `data` 文件夹在一起。
- macOS：提供通用版和 Intel 版 App 压缩包。
- Linux：提供 x86_64 和 ARM64 AppImage。
- Android：通用 APK 包含 arm64-v8a、armeabi-v7a 和 x86_64 原生音频引擎；自定义数据目录需要在系统设置中手动授予权限。
- iOS：提供未签名 IPA，需要自行签名安装。
- 每份可运行包附带 SHA-256 校验文件；Android 构建另附各 ABI 对应的引擎源码和重新链接材料。

这是预发布版本。升级前可备份本地配置；反馈问题时可从「设置 → 关于 → 导出日志」附上诊断信息。
