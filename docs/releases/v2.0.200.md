# Lazer v2.0.200

Lazer v2.0.200 是 v2.0.100 之后的稳定更新，集中完善播放可靠性、自适应界面、歌词与背景定制、系统集成和 Lua 插件平台。

Lazer v2.0.200 is the stable update after v2.0.100. It focuses on playback reliability, adaptive layouts, lyric and background customization, system integrations, and the Lua plugin platform.

## ▶️ 播放 / Playback

- 修复应用切到后台后偶尔无法重新取得云端曲目、以及音源临时失败后需要再次点击播放才能恢复的问题。
- 加固慢速缓存、快速连续切歌和 Lua 异步返回时的播放流水线；不可用曲目会按设置自动跳过。
- 专辑连续播放默认使用无缝衔接，在曲尾内完成后继曲目交接，并处理延迟返回和切歌竞争。
- 改进流媒体缓存、断点恢复、输出设备恢复和播放进度同步，减少卡顿、旧进度回跳和重复请求。

## 🪟 自适应界面 / Adaptive interface

- 统一手机、平板、桌面和电视布局；首次使用由操作系统判断设备类型，设置中仍可指定手机、平板、桌面或电视样式。
- 平板与移动端使用悬浮胶囊导航，当前歌曲在胶囊右侧显示圆形封面，描边跟随播放进度。
- 重做设置首页与二级页面、下拉选择、滑杆、返回手势和安全区处理，修复转场中背景、遮罩、焦点和页面位置异常。
- 电视端补充弹簧焦点动画、方向键选择和可配置的双击退出行为；桌面端关闭窗口时可选择仅关闭窗口或退出进程。
- 新增亮色、暗色和跟随系统主题模式，并继续统一 Apple 风格的非线性转场、页面层级与交互反馈。

## 🎤 歌词与背景 / Lyrics and backgrounds

- 悬浮歌词支持动态宽度、更紧凑的字重、锁定位置、点击穿透、自定义坐标，以及与正在播放页面一致的歌词间距。
- 桌面歌词支持逐字时间、翻译内容和 Lua 驱动的滚动样式。
- 自定义图片背景可选择实际展示区域，并可调节模糊强度。
- 流动背景改用正在播放页面的统一渲染实现；背景默认限制为 30 Hz，降低空闲渲染开销。

## 🧩 插件与主题 / Plugins and themes

- 新增 Lua 主题引擎和内置主题、页面布局抽象，可通过 Lua 重写主要视觉组件和歌词组件。
- 插件可决定首页展示的推荐、榜单和最近播放等区域，并提供编辑精选与心动模式支持。
- Lua 插件新增需用户授权的 WebSocket、Discord Rich Presence、一起听房间扩展和开发者控制台。
- 插件更新支持版本兼容检查、SHA-256 与清单校验、原子安装、取消下载和“跳过此版本”。

## 📱 系统集成 / System integration

- Android 与 iOS 新增播放次数桌面小组件。
- 修复 iOS 播放次数小组件在未签名 IPA 中缺少 `CFBundleExecutable`、且版本号与主应用不一致的问题。
- Discord Rich Presence 可显示当前歌曲、歌手、专辑和播放进度。
- 睡眠定时结束时释放音频焦点并停止前台播放服务。
- 新增系统代理兼容，改善中国大陆网络环境下 Web 版、更新检查和远程图片加载。
- 客户端与已安装插件在每次启动时自动检查更新，新版本会询问更新或跳过该版本。

## 🌍 Web 与性能 / Web and performance

- 浏览器端改用完整的原生界面和本机插件桥接，补充同源插件 HTTP 转发与 Vercel 区域路由。
- 优化首屏字体、CanvasKit 缓存、资源哈希、启动流程和动画快照，减少首次加载体积与重复下载。
- 修复中国大陆不开启代理时 Vercel 页面卡在“正在准备”或无法完成加载的问题。
- 清理不可见动画、重复背景绘制和过期播放状态，降低移动端与桌面端的持续资源占用。

## 📦 下载与升级 / Downloads and upgrades

| 平台 / Platform | 文件 / File |
| --- | --- |
| Windows x86_64 | `Lazer-Windows-x86_64.zip` |
| macOS Apple Silicon | `Lazer-macOS-aarch64.zip` |
| Linux x86_64 | `Lazer-Linux-x86_64.AppImage` |
| Linux ARM64 | `Lazer-Linux-aarch64.AppImage` |
| Android | `Lazer-Android-universal.apk` |
| iOS | `Lazer-iOS-aarch64.ipa` |

- Windows：下载并完整解压 ZIP，保持 EXE、DLL、资源与 `data` 文件夹在一起。
- macOS：使用 ad-hoc 签名，首次打开请右键选择“打开”，或在“系统设置 → 隐私与安全性”中放行。
- Linux：为 AppImage 添加执行权限后运行；运行时依赖已包含在包内。
- Android：通用 APK 使用仓库发布密钥签名，可直接覆盖安装相同签名的 v2.0.100。
- iOS：提供未签名 IPA，需使用 AltStore、SideStore 或 TrollStore 等工具自行签名。

每个可运行包都附带 SHA-256 校验文件。升级前建议备份本地配置；反馈问题时可从“设置 → 关于 → 导出日志”附上诊断信息。
