# Lazer v2.0.0-beta.5.fix

本次预发布修复歌单文字过渡时的残缺和末尾闪烁，让正在播放页的封面与文字从播放栏连续移动到对应位置。移动端加入 Bounce 弹簧动画，桌面端改用更从容的缓出动画，同时改善封面与歌词预加载、Android 数据存储和原生音频引擎首播。

## 动画与交互

- 修复点击歌单卡片进入详情、返回时，歌单名和数量在移动中被截断、最后几个字在落地前突然闪现的问题。过渡保留两端的文字排版，以移动、缩放和平滑交接呈现，避免逐帧换行或反复省略。
- 正在播放页复用歌单的封面与文字共享过渡：封面、歌名和歌手从底部播放栏移动到页面对应位置，关闭时返回播放栏；元素与页面共用动画进度。
- 移动端正在播放页加入带回弹的 Bounce 弹簧响应，保留进入途中抓取、下拉关闭、取消与再次抓取。
- 桌面端正在播放页打开和关闭改为约 600 毫秒的先快后慢动画，中途反向时从当前呈现位置和速度继续。
- 修复歌单返回时封面、标题和数量越过内容区域、出现重影的问题；交接后保持退场页的重复元素隐藏，并保留原页面滚动位置。
- 修复字体设置、定时关闭等二级页面与上一页控件重叠显示的问题，覆盖手机路由和桌面内嵌页面。
- 启用系统「减少动态效果」时直接完成页面与元素交接，保留键盘、遥控器和辅助功能操作。

## 播放页与缓存

- 切歌时即开始预加载清晰封面，并在内存中保留当前歌曲的已解码图片。再次打开正在播放页可直接复用；切换封面时释放旧缓存，同专辑封面共享解码结果。
- 同时预加载歌词，保留最近八首歌曲的解析结果，包括逐字时间与翻译。打开播放页复用已有请求；手动刷新和导入歌词修改会更新缓存，旧请求不会覆盖新歌曲。
- 歌词首帧直接对齐当前播放进度，避免进入页面时先挤在一起、等动画结束后才恢复。
- 封面或歌词在进入动画中加载完成时及时刷新画面，避免占位图一直停留到动画结束。

## Android 数据存储

- 设置中新增「数据存储」，可申请「所有文件访问权限」并指定 `/sdcard/Lazer` 等绝对路径。
- 更改目录后重启生效，已有缓存、歌词、导入字体和本地音乐索引会迁移到新目录，原文件保留。
- 支持恢复默认目录；所选目录不可访问时暂用应用默认目录，并保留原选择供恢复。

## 原生音频引擎

- 修复下一首预解码占用工作线程、阻挡当前歌曲首次播放的问题，避免需要反复切换播放/暂停才能启动。
- 修复读取器错过下载完成通知的问题。
- 对无法估算长度的网络流使用引擎自身的缓冲路径，避免把「未知」当成空缓冲一直等待。
- 保留兼容引擎的无缝队列预取行为。

## 其他修复

- 修复 Still Alive 彩蛋重播时残留的播放状态。
- 清理仅用于输出诊断信息的测试，保留播放、手势、文字排版、过渡交接与资源释放的回归检查。

## 下载与升级

- Windows：下载并完整解压 ZIP，保持 EXE、DLL 和 `data` 文件夹在一起。
- macOS：提供通用版和 Intel 版 App 压缩包。
- Linux：提供 x86_64 和 ARM64 AppImage。
- Android：通用 APK 包含 arm64-v8a、armeabi-v7a 和 x86_64 原生音频引擎；自定义数据目录需要在系统设置中手动授予权限。
- iOS：提供未签名 IPA，需要自行签名安装。
- 每份可运行包附带 SHA-256 校验文件；Android 构建另附各 ABI 对应的引擎源码和重新链接材料。

这是预发布版本。升级前可备份本地配置；反馈问题时可从「设置 → 关于 → 导出日志」附上诊断信息。
