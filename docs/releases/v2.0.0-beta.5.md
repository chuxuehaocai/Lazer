# Lazer v2.0.0-beta.5

本次预发布统一各平台的 Apple 风格弹簧动画，减少后台唤醒和封面解码开销，并修复歌单封面过渡闪烁、彩蛋重播和设置布局问题。「定时停止」改为每天重复的时间点，旧配置会自动迁移。

## 动画与交互

- 页面、播放页、封面、弹窗和交互反馈使用统一的弹簧响应；动画中途反向或切换目标时，从当前呈现位置和速度继续。
- 页面和播放器支持入场过程中抓取、拖动释放、取消及再次抓取，减少打断动画时的跳变；保留键盘、遥控器和辅助功能操作。
- 顶部精简歌曲信息从上向下进入；显示控制后，从当前位置向上淡出。动画中途切换仍保持连续。
- 放慢桌面正在播放页的封面切歌动画，移动端保持较快响应。
- 修复移动端正在播放页封面两侧阴影被裁切的问题，阴影围绕方形封面均匀扩散；歌词模式的小封面不显示阴影。
- 修复首页歌单卡片进入详情、返回及快速重开时封面层交接的空帧和闪烁，保留首页滚动位置。
- 按钮按压、拖出取消和电视焦点反馈接入统一响应；启用系统「减少动态效果」时避免不必要的位移和持续动画。

## 定时停止

- 从暂停时间段改为每天重复的暂停时间点，例如 `23:30`、`12:00`，支持添加多个时间点、编辑、删除、总开关及单项启停。
- 到点暂停当前歌曲，保留队列和进度；同一分钟的多个时间点合并执行，同一天不会反复触发。暂停后可以手动继续播放。
- 旧版本保存的暂停时段会迁移为各自的开始时间，不再使用结束时间或保持整段暂停。
- 回到前台会检查是否跨过时间点，处理等待中的播放命令越过暂停点的情况；更新后的设置持续保存到本机。
- 时间按设备本地时间计算；应用被系统完全挂起时，检查可能延后至恢复运行后执行。该功能暂停音乐，不退出应用或关闭设备。
- 移动端独立页面与桌面设置子视图使用同一配置，提供简体中文、繁体中文、英语和日语文案。

## 设置与统一界面

- 合并原有 `legacy` UI 目录、类型和主题入口，使用同一套主界面与 Apple 主题；桌面、手机、电视及手表按输入方式和屏幕大小调整布局。
- 保留旧偏好数据兼容，升级后继续读取背景、强调色等已有设置。
- 修复「高保真播放」中 DSP 链顺序等长选项造成的横向溢出，改善窄窗口、大字号和多语言布局。
- 整理设置、字体、歌单、手表和遥控器界面文案，补齐四语言翻译并清理废弃键。

## 背景与性能

- 低帧率动态背景按实际需要的时间唤醒并对齐显示刷新，避免设置为 10/30fps 后仍在每次屏幕刷新时执行背景回调；保留共享动画相位和背景精度。
- 隐藏、静态及暂停的背景释放唤醒任务；导航过渡结束后恢复背景，隐藏历史页面保持静止。
- 封面按显示尺寸和像素密度共享解码档位，本地与第三方大图也限制解码尺寸；保持长宽比并避免放大小图。
- 对异常超宽或超高封面增加纹理预算，降低持续保留的解码内存。原图导出保持完整分辨率。
- 暂停或没有歌曲时停止系统媒体控件的周期更新；暂停中的应用内定位仍立即同步系统时间轴，播放中保持低频发布并合并相同快照。
- 封面飞行在绘制阶段更新变换，旧封面、动画监听器、交接层和快照在不再需要时释放。
- 以上改进减少特定场景中的重复工作；实际 CPU、内存、GPU 占用和帧耗时仍受设备、刷新率、窗口及内容影响。

## 彩蛋与其他修复

- 修复 Still Alive 彩蛋播完后点击「重新播放」没有音乐、停在 Test Report 的问题：清除桌面后端残留的完成状态，并重新进入音频与歌词序列。
- 保留中途重播、连续重播、暂停并发和主音量同步，离开彩蛋会释放独立播放器。
- 修复 iOS simulator 验证在 Xcode 构建后长期卡住的处理路径：选择可用 runtime/device，增加安装启动日志、执行时限、进程组清理和一次受控恢复重试。
- 按 Xcode、SDK、架构及构建脚本精确缓存 simulator FFmpeg SDK，并将真实 simulator 引擎验证纳入发布门禁。

## 下载与升级

- Windows：下载并完整解压 ZIP，保持 EXE、DLL 和 `data` 文件夹在一起。
- macOS：提供通用版和 Intel 版 App 压缩包。
- Linux：提供 x86_64 和 ARM64 AppImage。
- Android：通用 APK 包含 arm64-v8a、armeabi-v7a 和 x86_64 原生音频引擎。
- iOS：提供未签名 IPA，需要自行签名安装。
- 每份可运行包附带 SHA-256 校验文件；Android 构建另附各 ABI 对应的引擎源码和重新链接材料。

这是预发布版本。升级前可备份本地配置；反馈问题时可从「设置 → 关于 → 导出日志」附上诊断信息。
