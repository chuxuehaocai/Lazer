# Lazer v2.0.0-beta.6

本次更新新增手机号／邮箱密码登录、登录 Cookie 导出和歌词间奏动画，修复原生音频引擎的连续播放与 iOS 锁屏切歌问题，并改进曲库缓存、封面过渡和自动更新提示。

## 登录与账户

- 登录卡片新增「密码登录」，同一输入框支持手机号和邮箱，提供密码显示／隐藏和忘记密码入口；登录后保留会话，账户信息使用脱敏显示。
- 设置中的网易云音乐账户新增「导出 Cookie」，可将当前登录 Cookie 复制到剪贴板；未登录时禁用，Navidrome 账户不显示该入口。
- 设置页移除「一起听」和「刷新曲库」入口。

## 歌词与界面

- 歌词新增前奏与间奏的三点动画，保留歌词中的显式空白时间段，并结合逐字歌词的结束时间识别较长间奏。
- 间奏动画跟随实际播放进度，暂停、拖动进度和切到后台时保持同步。
- 修复歌单封面在目标位置仍移动时的过渡衔接，保留当前呈现位置与速度，改善进入、返回和中途反向的连续性。
- 调整封面切换歌词布局时的弹簧节奏，响应更舒缓。
- 全新安装默认关闭浏览页背景画布，仅保留主题底色；正在播放页继续默认使用流动画布，已有背景设置保留。

## 播放与曲库

- 修复单曲循环、相邻歌曲使用同一音源时，预加载绑定干扰当前歌曲读取器或取消共用下载的问题。
- 修复下一首已准备完成后仍留在待处理队列、导致重复准备的问题，并改进手动切歌期间的队列衔接。
- 修复 iOS 在锁屏或后台切歌时释放音频会话、导致后续歌曲无法继续播放的问题；停止播放时仍正常释放会话。
- 专辑详情和歌手专辑分页复用正在进行的请求及本地缓存，减少重复打开或点击播放时的重复加载。
- 曲库刷新失败后短暂复用可用快照，避免弱网下反复请求；主动重试可立即重新加载。

## 更新检查

- 自动检查失败后在当前会话内重试，持续打开应用时也会定期确认是否到达每日检查时间。
- 更新提示被其他弹窗或后台状态挡住时保留结果，回到前台后继续展示，避免当天的提示被丢弃。
- 修复设备时间校正后未来时间戳阻止检查的问题，并为更新请求增加超时限制。

## 构建与许可证

- Android 通用 APK 仅包含 `arm64-v8a` 和 `armeabi-v7a`，本版不再提供 Android x86_64 构建。
- iOS 安装包补齐 FFmpeg 的 LGPL 许可证、构建资料与源码归档，并在打包后重新验证原生音频引擎及其导出符号。
- 项目许可证调整为 `AGPL-3.0-or-later`，补充第三方组件与素材声明；各独立组件和素材按其对应许可证分发。

## 下载与升级

- Windows：下载并完整解压 ZIP，保持 EXE、DLL 和 `data` 文件夹在一起。
- macOS：提供 Apple Silicon App 压缩包，使用 ad-hoc 签名。
- Linux：提供 x86_64 和 ARM64 AppImage，下载后需赋予可执行权限。
- Android：提供 ARM 通用签名 APK，可覆盖安装使用同一签名的旧版。
- iOS：提供未签名 IPA，需要自行签名安装。
- 每份可运行包附带 SHA-256 校验文件；Android 另附两个 ARM ABI 对应的引擎源码和重新链接材料。

这是预发布版本。反馈问题时可从「设置 → 关于 → 导出日志」附上诊断信息。
