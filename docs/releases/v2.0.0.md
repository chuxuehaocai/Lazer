# Lazer v2.0.0

Lazer 2.0 是 1.x 系列最终版 **v1.5** 之后的下一代正式版。它把流媒体平台迁移为可安装的 Lua 插件，并整合 2.0 测试版以来的全新界面、原生音频引擎、AutoMix、歌词与评论、下载缓存及跨平台系统集成。以下更新日志从 v1.5 之后累计。

> [!IMPORTANT]
> **从 1.5 升级 / Upgrading from 1.5**
>
> 1.x 系列已在 v1.5 冻结。2.0 保留本地播放、播放器与曲库缓存；音乐平台改为安装并启用对应的 Lua 插件后使用，插件 ZIP 不随客户端仓库或本 Release 分发。
>
> The 1.x line is frozen at v1.5. Lazer 2.0 keeps local playback, the player and the catalogue cache; streaming platforms are available after installing and enabling the matching Lua plugin. Plugin ZIPs are not bundled in the client repository or this release.

## 📝 2.0 更新 / What's new in 2.0

### 音乐平台与插件 / Music platforms and plugins

- 流媒体平台改为跨平台 ZIP 插件，在隔离的 Lua 沙箱中运行。客户端从插件清单读取平台、能力、登录方式和界面文案，不再内置固定服务列表。
- 网易云插件支持扫码、密码、短信和 Cookie 登录、会话恢复、个人歌单、我喜欢、收藏专辑、歌手、专辑、歌词、推荐、榜单、电台、评论、评论点赞和播放上报；源码独立维护在 `lazer_ncm` 仓库。
- 插件导入会校验清单、文件路径、体积和 Lua 入口，并以事务方式安装；失败时保留旧版本。插件管理页支持导入、启用、停用、卸载和重新导入。
- 新增插件市场：可从 HTTPS 插件源读取索引、搜索、安装、更新和取消下载，并检查目标系统与最低客户端版本；插件 ZIP 不放入客户端仓库，也不上传到市场。

### 全新界面与动效 / Interface and motion

- 全平台统一 Apple 风格设计系统：语义化系统色与字阶、玻璃导航、分组列表、封面取色主题，以及可中途打断、反向衔接的弹簧动画。
- 桌面端为侧边栏 + 完整播放条；移动端为底部胶囊导航 + 浮动迷你播放器；电视提供十英尺货架界面，手表提供独立布局，同一套页面按输入方式和屏幕尺寸适配。
- 正在播放页重做：桌面为 Apple Music 风格沉浸布局，移动端为封面 / 无边框歌词画布；AMLL 网格流动背景、队列与评论面板、M / L / Q / C / F 快捷键。
- 搜索改为独立页面并按歌曲、专辑、歌手和歌单分栏；新增歌手主页、专辑详情与收藏专辑页面，以及瀑布流评论卡片墙。
- 设置支持动画速率（0.5×–2.0×）、界面色板、动态 / 静态 / 纯色 / 自定义背景、DPI 80–175%、强制桌面 / 移动布局和车机形态；隐藏页面和静态背景会停止持续绘制。
- 新增听歌统计页面与桌面设置子视图；本地模式拥有独立首页和本地曲库搜索，并隐藏云端专属入口。

### 播放与音频引擎 / Playback and audio engine

- Windows、macOS、Linux、Android 和 iOS 接入原生音频引擎：FFmpeg 解码 + WASAPI / ALSA / CoreAudio / AAudio / RemoteIO 输出，支持无损、DSD / DoP、位完美输出和 DSP 链路。
- 高保真设置提供输出设备、独占输出、Bit-perfect、DSD 输出与倍率策略、响度归一、输出缓冲、EQ、限幅器和耳机串扰；所有诊断信息可在设置页查看并导出。
- 新增 AutoMix：按歌曲自身测算的节拍网格在拍点开始过渡，匹配响度并控制混合峰值，保留队列脚本指定的下一首。
- 播放模式和随机历史跨启动保存；随机模式下的上一首按真实播放顺序回退；切歌遇到音频卡死、被拒绝或流中断时自动恢复。
- 支持多平台同时登录、混合音源队列和独立音乐会话；队列条目在切换平台、退出账户或重启后仍归属原平台。
- 缓存与下载优先本地播放；首次播放边听边缓存，缓存歌曲、封面、歌词和翻译持久化，导入的 LRC 会复制到应用目录。
- Windows、macOS、Linux、Android 和 iOS 接入系统媒体控件；通知、锁屏、控制中心和灵动岛跟随播放状态。

### 歌词、评论与曲库 / Lyrics, comments and catalogue

- 歌词链路按 AMLL 方案重写：LRC / YRC 解析、逐字 emphasized 弹簧、35% 焦点带、渐进遮罩、距离模糊、按帧对齐和手动浏览后的平滑恢复。
- 歌词新增前奏与间奏三点动画，保留显式空白时间段；支持字号、字重、歌词字体调节、实时预览、多选复制和 PNG 导出。
- 新增热门 / 最新评论、分页加载和点赞；只有当前歌曲来自声明支持评论的云端平台时才显示评论入口。
- 曲库增加推荐歌单、私人雷达、榜单、电台、每日推荐和心动模式；专辑详情与歌手专辑分页复用进行中的请求和本地缓存。
- 本地音乐支持导入、扫描、搜索和独立索引；下载与缓存任务集中管理，可查看进度、取消或重试。

### 设置与系统集成 / Settings and system integration

- 定时停止支持多个每天重复的时间点，支持编辑、删除、总开关和单项启停；到点暂停当前歌曲并保留队列与进度，跨午夜按本地时间计算。
- Android 新增数据存储设置，可申请所有文件访问权限并指定 `/sdcard/Lazer` 等绝对路径；迁移缓存、歌词、导入字体和本地音乐索引。
- 新增字体导入与字体设置、局域网遥控器、均衡器、音频引擎导入、日志导出和构建信息展示。
- 更新检查支持每日检查、失败重试、超时和前台恢复提示；关于页显示构建提交与版本号。
- 设置页加入免费开源声明，提醒用户本项目为 AGPL-3.0-or-later 开源软件，付费购买即被骗。

### 稳定性与构建 / Reliability and builds

- 页面、弹窗、封面和文字共享元素动画保留中断时的位置与速度；修复歌单封面过渡截断、重影和空帧，返回时保留滚动位置。
- 设置、插件、专辑和页面转场增加构建期间通知保护与生命周期保护；停止重复的动画监听器和后台唤醒，降低封面解码与滚动开销。
- Android 17 后台音频限制适配、Android 发布签名校验、armeabi-v7a / arm64-v8a 原生库与 iOS 静态链接检查全部纳入 CI。
- 所有平台发布包均移除 FFmpeg 源码归档、许可证和构建资料，原生音频运行库继续随应用提供；打包后校验包结构和引擎导出符号。
- 项目许可证为 `AGPL-3.0-or-later`，第三方组件与素材声明见 `THIRD-PARTY-NOTICES.md`。
