# Lazer v2.0.0

Lazer 2.0 is the next generation after the final 1.x release, v1.5. It moves
streaming platforms into installable Lua plugins while keeping local playback,
the player and the catalogue cache in the client. This release also brings the
cross-platform Apple-style interface, native audio engine and multi-source
playback work from the beta series into the first stable 2.0 release.

## English

### Lua music platforms

- Streaming services are now installed as cross-platform ZIP plugins running in
  isolated Lua sandboxes. The client discovers platforms, capabilities and
  login methods from each plugin instead of shipping a fixed service list.
- The NetEase plugin supports QR, password, SMS and Cookie login, session
  restoration, personal playlists, favorites, saved albums, artists, albums,
  lyrics, recommendations, charts, radio, comments, comment likes and play
  reporting. Its source is maintained separately in `lazer_ncm`.
- Plugin imports are validated and staged transactionally. The plugin manager
  and market page support installation, updates, disabling, uninstalling,
  cancellation and platform compatibility checks. Plugin ZIPs are not bundled
  in this release repository or uploaded to the market.

### Playback and catalogue

- Local mode has its own Home Recent shelf and searches the local music library.
  Local navigation hides cloud-only Likes, while signed-in accounts from other
  platforms remain available.
- Multiple platform accounts and mixed-source queues can coexist. Queue entries
  retain their owning source through switching, logout and restart.
- Playback modes and shuffle history persist across launches. Previous in
  shuffle mode retraces the real listening order, and stream switching recovers
  from stalled or rejected sources without silently freezing playback.
- Audio and lyric caches are durable. Downloaded or automatically cached audio
  also stores timed lyrics and translations; imported LRC files are copied into
  application storage.
- The native audio engine now applies the configured gain before the first
  audible samples, including mute and very low volume settings.

### Interface and reliability

- Desktop, mobile, TV and watch layouts share the Apple-style design system,
  including mobile capsule navigation and the floating mini-player.
- Listening statistics are available as a mobile page and a desktop settings
  subview. Comments appear only when the current track belongs to a cloud
  platform that declares comment support.
- Shared cover and text transitions now retain their positions and velocities
  when interrupted. Settings, plugin pages, album pages and route transitions
  use build-safe notifications and lifecycle guards.
- The settings page includes plugin management, the plugin market, adaptive
  icon contrast and local/offline controls. Release diagnostics include the
  source commit and version stamp.

## 中文

### Lua 音乐平台

- 流媒体平台改为跨平台 ZIP 插件，在隔离的 Lua 沙箱中运行。客户端根据
  插件返回的平台、能力和登录方式动态显示，不再内置固定的平台列表。
- 网易云插件支持扫码、密码、短信和 Cookie 登录、自动恢复会话、个人歌单、
  我喜欢、收藏专辑、歌手、专辑、歌词、推荐、榜单、电台、评论、评论点赞和播放上报。
  源码独立维护在 `lazer_ncm` 仓库中。
- 插件管理支持安全导入、更新、停用、卸载、取消导入和平台兼容性检查。
  本次发布不把 Lua ZIP 放入客户端仓库，也不上传到插件市场。

### 播放与曲库

- 本地播放器首页保留最近播放，搜索改为搜索本地音乐库；本地模式隐藏云端专属的
  我喜欢入口，但其他平台的登录账户仍然保留。
- 支持多个平台同时登录和混合音源队列。切换音源、退出单个平台或重启后，队列条目仍然
  解析到它所属的平台。
- 播放模式和随机历史会跨启动保存；随机模式下点击上一首会按真实播放顺序回退，切歌遇到
  音频卡死、拒绝或流中断时会自动恢复。
- 音频和歌词缓存持久化。缓存或下载歌曲时同步保存逐行、逐字歌词和翻译；导入的 LRC
  会复制到应用目录，不再依赖原文件。
- 原生音频引擎会在第一批可听样本前应用用户音量，静音和极低音量启动也不会突然出声。

### 界面与稳定性

- 桌面、移动端、电视和手表共用 Apple 风格设计；移动端底栏和迷你播放器使用胶囊样式。
- 听歌统计支持移动端页面和桌面设置 subview。只有当前歌曲来自声明支持评论的云端平台时，
  才显示评论入口。
- 封面和文本共享元素动画会保留中断时的位置与速度；设置、插件、专辑和页面转场增加了
  构建期间通知保护与生命周期保护。
- 设置页加入插件管理、插件市场、自适应图标对比度、本地播放和离线缓存管理，并在关于页
  显示构建提交和版本信息。
