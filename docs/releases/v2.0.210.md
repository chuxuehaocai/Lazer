# Lazer v2.0.210

Lazer v2.0.210 是 v2.0.200 之后的稳定更新，集中修复界面卡顿和页面显示，并完善本地封面、歌词、电视端操作和桌面小组件。

Lazer v2.0.210 is the stable update after v2.0.200. It fixes interface stutter and page display, and improves local artwork, lyrics, television controls, and the desktop widget.

## 界面与性能 / Interface and performance

- 降低后台资源占用和界面卡顿。
- 修复部分页面下半屏不显示的问题。
- 修复进入插件市场等页面时，转场动画和上一页内容重叠渲染的问题。
- 刷新登录弹窗，并为设置中的外观与背景、本地音乐平台名称补上翻译。

## 播放与歌词 / Playback and lyrics

- 本地音频会读取文件内的 JPEG、PNG 和 WebP 封面，支持 MP3、FLAC、M4A、Ogg 和 WAV。已经在曲库里的文件也会补上封面；已有的网络封面或文件夹封面保持不变。
- 歌词可以显示罗马音。设置中可以关闭；没有罗马音数据时不会额外显示，数据来自歌词文件或插件。
- Lua 插件可以申请权限后开启 WebSocket 服务。

## 电视与小组件 / Television and widgets

- 电视端搜索可以弹出键盘，正在播放页面可以暂停和操作，不必退出应用。
- 桌面小组件从播放次数改为最近播放，保持原有布局并改为扁平样式。
- 小组件右上角使用圆角应用图标，文字使用内置 MiSans，亮暗色跟随系统，空状态文案已翻译。

## 下载与升级 / Downloads and upgrades

| 平台 / Platform | 文件 / File |
| --- | --- |
| Windows x86_64 | `Lazer-v2.0.210-Windows-x86_64.zip` |
| macOS Apple Silicon | `Lazer-v2.0.210-macOS-aarch64.zip` |
| Linux x86_64 | `Lazer-v2.0.210-Linux-x86_64.AppImage` |
| Linux ARM64 | `Lazer-v2.0.210-Linux-aarch64.AppImage` |
| Android | `Lazer-v2.0.210-Android-universal.apk` |
| iOS | `Lazer-v2.0.210-iOS-aarch64.ipa` |

- Windows：下载并完整解压 ZIP，保持 EXE、DLL、资源与 `data` 文件夹在一起。
- macOS：使用 ad-hoc 签名，首次打开请右键选择“打开”，或在“系统设置 → 隐私与安全性”中放行。
- Linux：为 AppImage 添加执行权限后运行；运行时依赖已包含在包内。
- Android：通用 APK 使用仓库发布密钥签名，可直接覆盖安装相同签名的 v2.0.200。
- iOS：提供未签名 IPA，需使用 AltStore、SideStore 或 TrollStore 等工具自行签名。

每个可运行包都附带 SHA-256 校验文件。升级前建议备份本地配置；反馈问题时可从“设置 → 关于 → 导出日志”附上诊断信息。
