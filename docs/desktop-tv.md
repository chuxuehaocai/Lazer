# 桌面与电视端交互

## 窗口与背景

Windows 和 Linux 可在「界面与布局」中切换 Inline 与经典标题栏，立即生效。Inline 将窗口按钮放在右上角胶囊内，并为页面操作保留顶部安全距离；经典模式把所有页面背景和图片裁切在独立标题栏下方，图片缩放和模糊不会溢出。

Windows 的浏览背景与正在播放背景均可选择「Windows DWM 云母材质」。原生实现使用 `DWMWA_SYSTEMBACKDROP_TYPE / DWMSBT_MAINWINDOW`，支持 Windows 11 22H2（build 22621）及以上；旧系统或合成不可用时回退到不透明主题底色。全屏进出后重新应用材质，离开云母模式恢复普通窗口背景。其他平台不显示此选项。

「内容不透明度」调整页面文字、按钮和卡片；浏览背景和播放背景各有独立的「背景不透明度」。DWM 的材质由系统合成，背景滑杆通过主题色遮罩调整材质可见程度，内容不透明度不会改变该遮罩。旧版错误使用的遮罩偏好不会迁移成透明文字。

切换桌面、平板、手机、电视布局后，根布局与密度立即更新。电视设备切换到其他布局仍保留遥控器方向键操作。设置仅在相关背景类型下展示动画帧率和质量，移除了内部网格参数说明。

打开正在播放页的入场动画期间暂停背景流动；纯色、图片与云母模式不再提取无用的封面调色板，云母由系统合成。这减少了打开播放器时并行的绘制工作；具体帧率仍取决于设备。

## 导航与播放

桌面界面以冷蓝强调色、蓝灰分层表面和半透明侧栏/播放栏组成。首页四张入口在桌面宽度下均分，封面拼贴保持静止；最近播放按行阅读，最多三列、三行一页，少量记录只占实际行数。更多按钮和右键打开曲目操作，不会启动播放。桌面导航、歌单和歌曲行可用 Tab 与 Enter，电视保留方向键与确认键。

设置选择器把当前值的勾选与键盘焦点边框分开。展开后焦点从当前项开始，Escape 取消并回到原控件；离开设置页面时菜单同步关闭。菜单宽度限制为 320 逻辑像素，长列表自动滚动至当前项。

正在播放页给歌词保留较宽的阅读区域，封面与元数据共用左侧对齐线，播放按钮和进度条在窗口中居中。低高度或大字体时改用紧凑封面与可滚动信息。只有正常播放且存在歌词时才自动隐藏控制栏，暂停或报错会恢复控制栏，便于继续播放或重试。

电视顶部导航右侧的歌曲封面是独立的「正在播放」入口，外圈表示播放进度。方向键可以在导航、封面和内容间移动，遥控器确认键打开播放器。头像、歌曲和其他操作沿用白色焦点环；头像的焦点环保持圆形。

当前音乐平台声明 `listenTogether` 能力时，桌面侧栏和电视顶栏右侧显示「一起听」，可创建房间或输入邀请码加入。平台切换后入口随能力更新，不支持的平台不显示入口。

桌面歌单的返回按钮、封面、说明和播放操作都属于列表顶部内容，滚动歌曲时一起滚出视口，不再保留额外固定工具条。

## 歌词窗口

- 悬浮歌词未锁定时，拖动文字或左侧拖动柄可移动窗口。文字以外的透明区域不拦截其他应用的鼠标操作。
- 锁定悬浮歌词后，整个窗口允许鼠标穿透，可从主窗口的歌词设置解除锁定。
- 桌面歌词的文字始终允许鼠标穿透，只在左侧拖动柄接受拖动。拖动后保存坐标，下次启用时恢复；移除显示器后会将位置限制在最近显示器的工作区内。
- Windows 原生交互区域使用 Flutter 的逻辑坐标并按窗口 DPI 换算。桌面歌词拖动不会抢占当前应用的焦点。
- 两种歌词窗口使用低透明度柔和阴影，避免多层高不透明度阴影叠成黑色底块。

## 验收场景

自动回归测试位于 `test/adaptive_chrome_regression_test.dart`，覆盖遥控器确认、独立播放入口位置、歌词鼠标区域、锁定行为，以及歌单顶部随列表滚动。

Windows 实机验证应检查：在桌面拖动歌词后重新启用、跨不同 DPI 显示器拖动、点击歌词周围的桌面图标、锁定悬浮歌词后点击文字下方的其他应用。电视应检查方向键往返头像与导航、打开正在播放后返回焦点，以及切换支持/不支持一起听的平台。

`test/interface_preferences_test.dart` 与 `test/window_backdrop_test.dart` 覆盖布局即时更新、透明度持久化与隔离、Windows 平台限制、材质失败回退、全屏重应用和过期响应。实机还需对照浅色/深色桌面背景检查 Mica，并分别验证 Inline 与经典模式下的图片边界。
