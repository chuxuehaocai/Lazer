# 缓存、字体与手表

## 边听边缓存

首次播放在线歌曲时直接播放，同时保存完整音频；只有下载完整的歌曲才会出现在
`本地音乐` 中，之后可以离线播放。默认保留 50 首，可在设置的下载区域
修改首数、清空缓存或切换策略：

- **最近缓存**：超限后移除最久没听的一首。
- **智能缓存**：优先保留最近 30 天听得更多的歌曲，次数相同时保留最近听过的。

用户手动下载、导入和扫描的歌曲不计入缓存首数，也不会被缓存策略删除。
歌单和专辑中长按歌曲进入批量管理，浮动操作条可以全选、下载所选或退出。
每日推荐现在以独立歌单打开，显示完整推荐歌曲。

## 字体与播放器

`设置 → 字体自定义` 可以在内置 MiSans、系统字体和导入字体之间选择。
导入支持 OTF / TTF，文件会复制到应用目录，重启后继续使用。
各类文字仍可分别调节字号与字重。歌词视图固定显示小封面，随控件整体淡入淡出；
正在播放页的更多菜单可创建一起听房间或查看已有房间状态。

## 普通 Android 手表

同一个 Android APK 根据标准 Android 硬件特征和系统配置识别手表与圆屏；
未报告手表标识的完整 Android 设备还会按小型方屏识别（最长边不超过 320 dp，
长宽比接近 1，排除分屏窗口）。
没有依赖 Wear OS 服务或专有 API。方屏使用紧凑列表，圆屏额外留出四角安全空间。
手表默认静态背景，提供播放、队列、最近播放、本地音乐、推荐歌单、搜索、
手机号验证码登录和本地歌曲导入。内容可以上下滚动，避免在小屏上挤压控件。
