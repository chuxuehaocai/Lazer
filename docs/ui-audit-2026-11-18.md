## 布局与交互

- 手机布局使用统一的 **720 逻辑像素**断点，按界面缩放后的实际可用宽度判断。窄于该值时，自动、桌面、平板偏好都回退到手机布局；明确的 TV 布局继续使用遥控器界面。手机与平板范围不再重叠。
- 主界面、完整播放器、独立播放路由、目录详情播放栏和窗口框架共用判断逻辑，移除播放器的 624px 特例及主界面底栏的 1000px 特例。
- 手机与窄桌面都显示实际可操作的迷你播放栏：歌曲入口、播放/暂停、下一首。移除原先透明的 1×1 播放组件与仅封面的替代实现。
- 目录详情复用 `AppPlayerBar`，进度条复用 `PlayerSeekBar`。取消拖动及拖动期间切歌不会错误提交 seek。紧凑按钮使用 44px 命中区域；宽屏底栏随宽度连续排布，大字体时允许增高。
- 合并重复的平板/手机内容树，并给内容容器固定的 GlobalKey。缩放窗口时保留搜索输入、页面状态和详情历史；保留 TV 的独立组合。
- 修复 Q/L/C 快捷键操作隐藏手机状态的问题，桌面模式直接切换当前可见的侧面板。
- 修复首页、歌手页专辑/歌单架及歌曲卡在放大文字下的溢出，共享并缓存文字高度测量；移除重复的字体 token 定义。

## 生命周期与资源

- 歌词只在逐字高亮或弹簧仍运动时逐帧采样。隐藏和后台停止；重新显示、同句回退和进入下一句能及时恢复。强调字的尾部浮动完整结束后再停帧。
- 滚动列表隐藏或进入后台时清除旧滚轮惯性，恢复后不会自行继续滚动。
- 网络目录更换来源后重新请求，丢弃旧列表及旧索引完成回调；长目录改为懒加载，窄屏操作按钮换行。
- 网络输入框复用拥有控制器生命周期的共享对话框，避免退出动画访问已释放对象。
- 本地扫描只关闭自己创建的进度弹窗，用户提前返回后不会再弹出其他页面；进度资源在退出动画结束后释放。
- 插件市场、开发控制台和 TV 搜索正确处理来源更换、借用会话所有权及迟到请求结果。

审查覆盖主界面、播放器、浏览/搜索/收藏/歌单/歌手/设置/登录、插件页面、窗口与导航、TV 页面、动画、歌词与桌面歌词、主要共享 widgets、本地音乐、网络源/播客页面及手表界面的相关布局和生命周期路径。

## 帧率与性能

- 浏览和播放动态背景默认 `0`，含义为跟随显示器 VSync，不设应用层帧率上限；已保存的手动限帧偏好继续生效。移除 Web 强制 30fps 上限。
- 隐藏、静止和暂停的界面仍停止无用工作，不通过忙循环产生无效帧。
- 删除无消费者的“网格质量推导帧率”代码，渲染精度只控制网格密度。
- 帧率面板按当前显示器刷新率计算预算；异常刷新率回退 60Hz。吞吐使用 UI/Raster 中较慢的阶段判断，不把两个可并行阶段相加。修复窄屏面板溢出及日志错误显示 `0 fps`。

Windows profile 采样使用本地生成封面、48 首歌曲和 120 行逐字歌词，在 144Hz 显示器上各测动态、静态、Mica 背景四次。它衡量播放器进入和随后 1.6 秒的引擎帧耗时，不包含真实音频解码或网络请求。详细原始数据见 [validation/ui-audit-2026-11-18.json](validation/ui-audit-2026-11-18.json)。

| 窗口 | UI P95 范围 | Raster P95 范围 | 超过 6.94ms 预算 |
| --- | --- | --- | --- |
| 1280×800 | 0.307–0.483ms | 2.378–6.034ms | 9 / 2688 帧 |
| 390×800 | 0.086–0.142ms | 0.302–2.471ms | 1 / 2122 帧 |

这些是每次采样的 P95 范围，不能当作所有设备的帧率保证。已通过真实 Windows 窗口检查宽屏浏览、窄屏完整播放器及窄屏底部播放栏。复现命令及宽度参数见 [../tool/benchmarks/README.md](../tool/benchmarks/README.md)。

## 验证

- 全量 `flutter test --no-pub`：650 项通过；2 项网易云插件合约测试因缺少外部插件源码而跳过。日志：`build/ui-audit-final-tests.log`。
- 全量 `flutter analyze --no-pub`：无问题。日志：`build/ui-audit-final-analyze.log`。
- Chrome 平台背景测试：3 项通过，覆盖 120Hz 不限帧、隐藏停帧及 30fps 切回不限帧。日志：`build/ui-audit-web-tests.log`。
- 响应式测试包括断点两侧、Android/Windows 相同控件、实际播放/下一首/歌曲入口点击、1×/1.5× DPI 缩放保留搜索状态、720px 宽屏和 300% 字体播放栏。
- 14 个非空浏览/设置页面在 320/720/1280 宽度和 1.6× 字体下检查布局和滚动。
- 动画测试包括 120Hz 每帧更新、30fps 切回不限帧、隐藏停帧、缓存释放、歌词 4ms 连续帧和恢复唤醒。

- Windows profile 基准构建成功；正常入口 `lib/main.dart` 的 Windows release 构建成功，输出 `build/windows/x64/runner/Release/lazer_nextgen.exe`。发布构建日志：`build/ui-audit-release-build.log`。原生依赖的类型转换、代码页和对齐警告仍存在，未影响构建。
