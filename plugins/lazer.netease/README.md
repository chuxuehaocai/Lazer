# 网易云音乐 Lua 插件

这是 Lazer 音乐平台插件协议的网易云音乐实现，使用宿主提供的 HTTPS、加密、Cookie 与隔离存储接口。Lua VM 不访问文件系统、进程或动态库。

## 打包与安装

在仓库根目录运行：

```powershell
dart run tool/package_netease_lua.dart
```

生成的 `dist/lazer.netease-1.0.3.zip` 可在「设置 → 插件管理 → 导入 ZIP」中安装。插件默认启用，安装后可选择「网易云音乐」并使用二维码、Cookie、手机号验证码或密码登录。

账号 Cookie 仅保存在此插件的数据目录中，不会写入插件包、日志或错误文本。

## 支持能力

- 搜索歌曲、专辑、艺人和歌单
- 专辑、艺人、歌单与收藏歌曲浏览
- 音源、歌词、每日推荐和听歌排行
- 登录、收藏、歌单编辑与播放记录上报
- 歌曲热门评论、最新评论、分页和点赞；评论入口随歌曲所属插件启用和停用

网易云服务的可用接口和音质会因账号、歌曲、地区及服务端策略而异。
